## 📊 数据流程

### 1. 数据采集（Flask爬虫）
```
携程API → Flask爬虫 → 数据清洗 → HDFS存储
数据路径：/tourism/raw/YYYYMMDD/*.jsonl
数据格式：JSONL（每行一条JSON记录）
```

### 2. 数据存储（Hadoop + Hive）
```sql
-- Hive外部表（读取HDFS数据）
CREATE EXTERNAL TABLE fuzhou_reviews (
    review_id STRING,
    spot_id STRING,
    spot_name STRING,
    visitor_name STRING,
    rating DOUBLE,
    review_content STRING,
    travel_date STRING,
    review_date STRING,
    ...
)
ROW FORMAT SERDE 'org.apache.hive.hcatalog.data.JsonSerDe'
LOCATION '/tourism/raw/';
```

### 3. 数据分析（SpringBoot）
```java
// 通过Hive JDBC查询
@Autowired
@Qualifier("hiveJdbcTemplate")
private JdbcTemplate hiveJdbcTemplate;

// 执行Hive SQL
String sql = "SELECT spot_name, COUNT(*) as count FROM fuzhou_reviews GROUP BY spot_name";
List<Map<String, Object>> result = hiveJdbcTemplate.queryForList(sql);
```

## 🔐 认证流程（SaToken）

### 登录流程
```
1. 前端POST /api/auth/login {username, password}
2. 后端验证用户名密码（BCrypt）
3. SaToken生成token，存储到Redis
4. 返回token和用户信息
5. 前端保存token到localStorage
6. 后续请求携带token：Header['satoken'] = token
7. SaToken拦截器自动验证token
```

### 权限验证
```java
// 拦截器配置
registry.addInterceptor(new SaInterceptor(handle -> StpUtil.checkLogin()))
    .addPathPatterns("/**")
    .excludePathPatterns("/api/auth/login", "/api/health/**");
```

## 🚀 快速启动

### 1. 环境准备
- JDK 1.8+
- MySQL 8.0（端口3306）
- Redis（端口6379）
- Hive（端口10000）

### 2. 初始化数据库
```bash
# MySQL
mysql -u root -p < src/main/resources/sql/01_mysql_init.sql

# Hive
hive -f src/main/resources/sql/02_hive_init.sql
```

### 3. 配置连接
编辑`application.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/tourism_db
    username: root
    password: 你的密码
  
  redis:
    host: localhost
    port: 6379

hive:
  jdbc:
    url: jdbc:hive2://localhost:10000/default
```

### 4. 启动应用
```bash
mvn spring-boot:run
```

### 5. 测试接口
```bash
# 登录
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'

# 获取数据概览
curl http://localhost:8080/api/analysis/overview \
  -H "satoken: 你的token"

# 查看接口文档
访问：http://localhost:8080/doc.html
```

## 📝 核心SQL示例

### Hive查询示例
```sql
-- 1. 景区评论数统计
SELECT spot_name, COUNT(*) as review_count
FROM fuzhou_reviews
GROUP BY spot_name
ORDER BY review_count DESC;

-- 2. 月度游客趋势
SELECT 
    SUBSTR(travel_date, 1, 7) as month,
    COUNT(*) as visitor_count
FROM fuzhou_reviews
WHERE YEAR(travel_date) = 2024
GROUP BY SUBSTR(travel_date, 1, 7)
ORDER BY month;

-- 3. 评分分布
SELECT 
    CAST(rating AS INT) as rating_level,
    COUNT(*) as count
FROM fuzhou_reviews
GROUP BY CAST(rating AS INT)
ORDER BY rating_level DESC;

-- 4. 季节性分析
SELECT 
    CASE 
        WHEN MONTH(travel_date) IN (3,4,5) THEN '春季'
        WHEN MONTH(travel_date) IN (6,7,8) THEN '夏季'
        WHEN MONTH(travel_date) IN (9,10,11) THEN '秋季'
        ELSE '冬季'
    END as season,
    COUNT(*) as visitor_count
FROM fuzhou_reviews
WHERE YEAR(travel_date) = 2024
GROUP BY 
    CASE 
        WHEN MONTH(travel_date) IN (3,4,5) THEN '春季'
        WHEN MONTH(travel_date) IN (6,7,8) THEN '夏季'
        WHEN MONTH(travel_date) IN (9,10,11) THEN '秋季'
        ELSE '冬季'
    END;
```

## 🎯 核心技术点

1. **SaToken认证**：轻量级权限认证框架，支持Redis持久化
2. **Hive JDBC**：通过JDBC连接Hive，执行SQL查询大数据
3. **MyBatis Plus**：简化MySQL数据库操作
4. **统一响应格式**：Result<T>封装，前端统一处理
5. **全局异常处理**：@RestControllerAdvice统一捕获异常
6. **接口文档**：Knife4j自动生成，访问/doc.html

## 📌 注意事项

1. **Hive查询性能**：
   - 建议为大表创建分区
   - 使用WHERE子句过滤数据
   - 避免SELECT *

2. **SaToken Token管理**：
   - Token默认30天有效期
   - 存储在Redis中
   - 支持并发登录

3. **数据同步**：
   - Flask爬虫定时爬取数据到HDFS
   - Hive外部表自动读取最新数据
   - 无需手动同步
