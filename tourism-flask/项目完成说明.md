## 🚀 快速启动

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境
复制`.env.example`为`.env`并修改配置

### 3. 启动服务

**方式一：使用启动脚本（推荐）**
```bash
# 终端1：启动Redis
redis-server

# 终端2：启动Celery
start_celery.bat

# 终端3：启动Flask
start.bat
```

**方式二：手动启动**
```bash
# 启动Redis
redis-server

# 启动Celery Worker
celery -A celery_worker.celery_app worker --loglevel=info -P solo

# 启动Flask
python app.py
```

### 4. 测试接口

访问：http://localhost:5000

```bash
# 测试API
curl http://localhost:5000/api/scenic/list
```

## 📊 数据流程

```
前端调用API
    ↓
Flask创建任务记录（MySQL）
    ↓
Celery异步执行爬虫
    ↓
携程/去哪儿/马蜂窝爬取数据
    ↓
数据清洗（DataCleaner）
    ↓
保存到HDFS（JSON Lines格式）
    ↓
更新任务状态（成功/失败）
```

## ⚠️ 重要说明

### 1. 爬虫选择器需要调整

由于无法实时访问旅游网站，爬虫代码中的CSS选择器是**通用策略**，实际使用时需要：

1. **打开目标网站**（如携程）
2. **使用浏览器开发者工具**（F12）分析HTML结构
3. **调整`ctrip_crawler.py`中的选择器**

示例：
```python
# 当前代码（通用选择器）
review_items = soup.select('.commentList, .reviews-list, .comment-list')

# 需要根据实际网站调整为
review_items = soup.select('.actual-class-name-from-website')
```

### 2. 携程网站结构可能变化

携程可能会：
- 更改HTML结构
- 使用动态加载（需要Selenium/Playwright）
- 增强反爬虫机制

建议：
- 定期检查网站结构
- 实现Ajax接口爬取（如果页面是动态加载）
- 使用Playwright处理JavaScript渲染

### 3. 反爬虫建议

如果频繁被封禁：
1. 启用代理IP池
2. 增加请求延迟（2-5秒）
3. 降低并发数量
4. 使用Selenium模拟真实浏览器

### 4. HDFS依赖

系统需要Hadoop环境：
```bash
# 检查HDFS是否运行
jps | grep NameNode

# 启动HDFS
start-dfs.sh
```

如果没有Hadoop，可以修改`hdfs_client.py`保存到本地文件。
