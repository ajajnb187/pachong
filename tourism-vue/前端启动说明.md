# 福州旅游数据分析可视化平台 - 前端

## 项目简介

基于 Vue 3 + Vite + Element Plus + ECharts 的现代化数据可视化平台，用于展示福州旅游景区的数据分析结果。

## 技术栈

- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **UI 框架**: Element Plus
- **图表库**: ECharts 5
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **HTTP 客户端**: Axios
- **样式**: SCSS

- 用户登录

- 景区总数、评论总数、平均评分、评论人数统计

- 排行榜列表 (金银铜牌效果)

### 4. 客源地分析
- 游客来源省份分布 (饼图)
- 游客来源城市 TOP10 (柱状图)
- 游客年龄性别分布 (堆叠柱状图)

### 5. 季节性分析
- 景区选择器
- 年份选择器
- 月度游客量趋势图 (折线图)
- 季节分布 (饼图)

- 推荐月份展示

- 景区基本统计
- 评分趋势图
- 游客量趋势图
- 评论详情表格

## API 配置

后端 API 地址配置在 `vite.config.js`:

```javascript
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

## 开发注意事项

1. **认证机制**: 使用 Sa-Token，token 存储在 localStorage 和 Pinia store
2. **请求拦截**: 自动在请求头添加 `satoken` 字段
3. **响应拦截**: 统一处理错误提示和 token 失效
4. **图表自适应**: 所有图表支持窗口大小变化自动调整
5. **移动端适配**: 使用 Element Plus 栅格系统实现响应式布局

## 常见问题

### 1. 安装依赖失败
```bash
# 清除缓存
npm cache clean --force
# 重新安装
npm install
```

### 2. 启动报错
```bash
# 删除 node_modules 和 package-lock.json
rm -rf node_modules package-lock.json
# 重新安装
npm install
```

### 3. API 请求失败
- 检查后端服务是否启动
- 检查 vite.config.js 中的代理配置
- 检查浏览器控制台的网络请求

## 开发建议

1. 使用 Vue DevTools 进行调试
2. 参考 Element Plus 官方文档进行组件使用
3. 使用 ECharts 官方示例进行图表配置
4. 遵循 Vue 3 Composition API 最佳实践
