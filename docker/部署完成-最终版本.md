## 🎯 核心配置说明

### 1. MapReduce本地模式
`hadoop.env` 中的关键配置：
```bash
MAPRED_CONF_mapreduce_framework_name=local
```

### 2. Hive优化配置
```bash
HIVE_SITE_CONF_hive_execution_engine=mr
HIVE_SITE_CONF_hive_exec_mode_local_auto=true
HIVE_SITE_CONF_hive_fetch_task_conversion=more
HIVE_SITE_CONF_hive_fetch_task_aggr=true
```

### 3. 为什么不挂载hive-site.xml？
- bde2020镜像使用`sed`命令动态生成配置
- Docker挂载的文件无法被`sed -i`修改（Device or resource busy）
- 解决方案：使用环境变量，让镜像自己生成配置
