# 福州旅游景区数据采集系统全链路技术分析

## 一、系统架构概述

### 1.1 技术栈
- **Web框架**: Flask（提供RESTful API）
- **任务队列**: Celery + Redis（异步任务处理）
- **数据库**: MySQL（任务元数据管理）
- **分布式存储**: Hadoop HDFS（海量数据存储）
- **数据处理**: Hive（数据仓库与分析）
- **爬虫框架**: Python Requests（HTTP请求）

### 1.2 核心组件
```
管理员前端 
    ↓ HTTP POST
Flask API (app.py)
    ↓ 创建任务记录
MySQL数据库 (models/task.py)
    ↓ 发送异步任务
Celery Worker (celery_worker.py)
    ↓ 执行爬虫
携程爬虫 (crawlers/ctrip_real_crawler.py)
    ↓ 数据清洗
数据清洗器 (utils/data_cleaner.py)
    ↓ 存储数据
HDFS客户端 (utils/hdfs_client.py)
    ↓ 保存文件
Hadoop HDFS (/tourism/raw/YYYYMMDD/*.jsonl)
    ↓ 数据分析
Hive建表查询
```

## 二、数据存储策略分析

### 2.1 存储策略：增量存储（非覆盖）

**关键代码**: `utils/hdfs_client.py` 第27-88行

```python
def save_data(self, data_list, task_id, scenic_spot_name, data_source):
    date_str = datetime.now().strftime('%Y%m%d')      # 日期：20251211
    timestamp = datetime.now().strftime('%H%M%S')     # 时间：021823
    spot_pinyin = self._pinyin_convert(scenic_spot_name)  # 拼音：fuzhou
    
    # 构造路径
    dir_path = f"/tourism/raw/{date_str}"
    file_name = f"{data_source}_{spot_pinyin}_{task_id}_{timestamp}.jsonl"
    file_path = f"{dir_path}/{file_name}"
    # 示例: /tourism/raw/20251211/ctrip_fuzhou_20_021823.jsonl
```

**存储特点**：
1. ✅ **每次爬取生成独立文件**：文件名包含任务ID和时间戳，确保唯一性
2. ✅ **不覆盖历史数据**：新数据追加到新文件，旧数据保留
3. ✅ **按日期分目录**：便于按日期范围查询和管理
4. ✅ **支持数据追溯**：每个文件对应一次爬取任务，可追溯数据来源

### 2.2 为什么采用增量存储？

**论文要点**：

1. **数据时效性**: 旅游评论是动态增长的，用户持续发布新评论
2. **历史对比**: 保留多次爬取结果，可分析评论增长趋势
3. **Hive兼容**: Hive外部表支持读取目录下所有文件，自动合并数据
4. **容错性**: 单次爬取失败不影响历史数据
5. **审计追踪**: 每个文件记录了爬取时间和任务ID，便于数据治理

```python
def crawl_reviews(self, spot_id, spot_name, target_count):
    """爬取评论数据（生成器模式）"""
    
    # 6.1 调用携程景区列表API
    api_url = "https://m.ctrip.com/restapi/soa2/18109/json/getAttractionList"
    payload = {
        "cityId": 164,              # 福州城市ID
        "pageIndex": 1,
        "pageSize": 100,            # 每页100个景区
        "type": 0,
        "channel": "H5",
        "head": {"clientType": "H5"}
    }
    
    response = self.session.post(api_url, json=payload, timeout=15)
    data = response.json()
    
    # 6.2 解析景区列表
    attractions = data.get('result', {}).get('list', [])
    
    # 6.3 遍历每个景区
    for attraction in attractions:
        business_id = attraction.get('businessId')    # 景区ID
        poi_name = attraction.get('poiName')          # 景区名称
        detail_url = attraction.get('detailUrl')      # 详情页URL
        
        # 6.4 访问景区详情页，获取真实用户评论
        if detail_url and count < target_count:
            user_reviews = self._crawl_user_reviews_from_detail(
                detail_url, 
                business_id, 
                poi_name, 
                min(5, target_count - count)  # 每个景区最多5条
            )
            
            # 6.5 逐条返回评论（生成器模式）
            for review in user_reviews:
                yield review  # 返回一条评论数据
                count += 1
```

**携程评论API调用** (`crawlers/ctrip_real_crawler.py` 第182-299行):
```python
def _crawl_user_reviews_from_detail(self, detail_url, spot_id, spot_name, limit=5):
    """从详情页爬取真实用户评论"""
    
    # 提取景区ID（从URL中）
    match = re.search(r'/sight/(\d+)\.html', detail_url)
    if not match:
        return []
    
    sight_id = match.group(1)
    
    # 调用携程评论API
    comment_api = "https://m.ctrip.com/restapi/soa2/13444/json/getCommentCollapseList"
    payload = {
        "resourceId": int(sight_id),
        "resourceType": 11,          # 11=景区
        "pageIndex": 1,
        "pageSize": limit,
        "sortType": 3,               # 3=按时间排序
        "head": {"clientType": "H5"}
    }
    
    response = self.session.post(comment_api, json=payload, timeout=15)
    result = response.json()
    
    # 解析评论数据
    items = result.get('result', {}).get('items', [])
    
    for item in items:
        # 提取评论字段
        content = item.get('content', '')
        score_desc = item.get('scoreDesc', '5.0')
        author = item.get('userInfo', {}).get('userNick', '携程用户')
        publish_time = item.get('publishTime', '')
        publish_tag = item.get('publishTypeTag', '')
        
        # 解析日期（Unix时间戳或格式化日期）
        review_date = parse_date(publish_time, publish_tag)
        travel_date = review_date
        
        # 构造评论对象
        review = {
            'review_id': str(uuid.uuid4()),
            'spot_id': str(spot_id),
            'spot_name': spot_name,
            'visitor_name': author,
            'rating': float(score_desc.replace('分', '')),
            'review_content': content[:500],
            'review_images': '[]',
            'travel_date': travel_date,      # YYYY-MM-DD
            'review_date': review_date,      # YYYY-MM-DD
            'helpful_count': 0,
            'visitor_level': '',
            'visitor_location': '',
            'data_source': 'ctrip',
            'crawl_time': datetime.now().strftime('%Y-%m-%d %H:%M:%S')
        }
        
        reviews.append(review)
    
    return reviews
```

**论文要点**:
1. **两阶段爬取**:
   - 第一阶段：调用景区列表API，获取福州所有景区
   - 第二阶段：调用评论API，获取每个景区的用户评论

2. **数据来源**:
   - 景区列表API: `getAttractionList` (cityId=164)
   - 评论API: `getCommentCollapseList` (resourceType=11)

3. **数据特点**:
   - 真实用户评论（非模拟数据）
   - 包含历史日期（travel_date, review_date）
   - 时间跨度：2016-2025年（近10年）

4. **生成器模式**:
   - 使用`yield`逐条返回数据
   - 节省内存，支持大规模爬取
   - 实时反馈进度

```python
class DataCleaner:
    @staticmethod
    def clean_review_data(raw_data):
        """清洗评论数据"""
        
        # 7.1.1 字段验证
        if not raw_data.get('review_content'):
            return None  # 过滤空评论
        
        # 7.1.2 去除HTML标签
        content = re.sub(r'<[^>]+>', '', raw_data['review_content'])
        
        # 7.1.3 标准化日期格式
        travel_date = validate_date(raw_data.get('travel_date'))
        review_date = validate_date(raw_data.get('review_date'))
        
        # 7.1.4 标准化评分
        rating = float(raw_data.get('rating', 5.0))
        rating = max(1.0, min(5.0, rating))  # 限制在1-5
        
        # 7.1.5 构造清洗后的数据
        return {
            'review_id': raw_data['review_id'],
            'spot_id': str(raw_data['spot_id']),
            'spot_name': raw_data['spot_name'].strip(),
            'visitor_name': raw_data['visitor_name'].strip(),
            'rating': rating,
            'review_content': content.strip()[:500],
            'review_images': raw_data.get('review_images', '[]'),
            'travel_date': travel_date,
            'review_date': review_date,
            'helpful_count': int(raw_data.get('helpful_count', 0)),
            'visitor_level': raw_data.get('visitor_level', ''),
            'visitor_location': raw_data.get('visitor_location', ''),
            'data_source': 'ctrip',
            'crawl_time': raw_data['crawl_time']
        }
```

**论文要点**:
- 数据质量控制：过滤无效数据
- 字段标准化：统一格式
- 实时进度更新：每爬取一条数据更新一次进度

```python
def save_data(self, data_list, task_id, scenic_spot_name, data_source):
    # 8.2.1 生成文件路径
    date_str = datetime.now().strftime('%Y%m%d')      # 20251211
    timestamp = datetime.now().strftime('%H%M%S')     # 021823
    spot_pinyin = self._pinyin_convert(scenic_spot_name)  # fuzhou
    
    dir_path = f"/tourism/raw/{date_str}"
    file_name = f"{data_source}_{spot_pinyin}_{task_id}_{timestamp}.jsonl"
    file_path = f"{dir_path}/{file_name}"
    # 示例: /tourism/raw/20251211/ctrip_fuzhou_20_021823.jsonl
    
    # 8.2.2 创建HDFS目录
    self.client.makedirs(dir_path)
    
    # 8.2.3 转换为JSONL格式（每行一条JSON）
    jsonl_data = '\n'.join([
        json.dumps(item, ensure_ascii=False) 
        for item in data_list
    ])
    
    # 8.2.4 写入HDFS
    with self.client.write(file_path, encoding='utf-8', overwrite=True) as writer:
        writer.write(jsonl_data)
    
    logger.info(f"数据已保存到HDFS: {file_path}, 共{len(data_list)}条记录")
    return file_path
```


**论文要点**:
1. **文件格式**: JSONL（JSON Lines）
   - 每行一条JSON记录
   - 支持Hive JsonSerDe直接解析
   - 便于流式处理

2. **文件命名规则**:
   - 数据源（ctrip）
   - 景区拼音（fuzhou）

3. **容错机制**:

## 五、核心技术特点

### 5.1 异步任务处理

**优势**:
- HTTP请求秒级响应，不阻塞前端
- 支持长时间运行任务（几分钟到几小时）
- 支持分布式部署（多Worker并发）

### 5.2 增量存储策略

**优势**:
- 每次爬取生成独立文件，不覆盖历史数据
- 支持数据追溯和版本管理
- Hive自动合并多个文件

### 5.3 容错机制

**HDFS失败降级**:
```python
try:
    # 尝试写入HDFS
    self.client.write(hdfs_path, data)
except Exception as e:
    # 降级到本地文件
    with open(local_path, 'w') as f:
        f.write(data)
```

**任务失败记录**:
```python
try:
    # 执行爬取
    crawl_data()
except Exception as e:
    # 记录错误信息
    task.status = 'failed'
    task.error_msg = str(e)
    db.commit()
```

### 5.4 实时进度反馈

```python
# 每爬取1条数据更新一次
task.progress = int((count / target_count) * 100)
task.actual_count = count
db.commit()

# Celery状态更新
self.update_state(state='PROGRESS', meta={'progress': 50, 'count': 250})
```
