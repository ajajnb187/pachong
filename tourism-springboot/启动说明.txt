========================================
福州旅游景区数据分析系统 - 快速启动指南
========================================

【前置条件】
1. JDK 1.8+ 已安装
2. Maven 3.6+ 已安装
3. MySQL 8.0+ 已启动（端口3306）
4. Hive服务已启动（端口10000）
5. Flask爬虫已爬取数据到HDFS

【第一步：初始化MySQL数据库】
1. 使用MySQL客户端连接到数据库
2. 执行SQL脚本：
   mysql -u root -p < src/main/resources/sql/01_mysql_init.sql

【第二步：初始化Hive表】
1. 连接到Hive
   beeline -u jdbc:hive2://localhost:10000
2. 执行SQL脚本：
   source src/main/resources/sql/02_hive_init.sql

或直接运行：
   hive -f src/main/resources/sql/02_hive_init.sql

【第三步：配置数据库连接】
编辑 src/main/resources/application.yml：

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/tourism_db
    username: root
    password: 你的MySQL密码

hive:
  jdbc:
    url: jdbc:hive2://localhost:10000/default
    username: hadoop

【第四步：启动应用】
方式1 - Maven命令：
   mvn spring-boot:run

方式2 - IDE运行：
   右键 TourismSpringbootApplication.java -> Run

【第五步：验证】
1. 访问健康检查接口：
   http://localhost:8080/api/health

2. 测试Hive连接：
   http://localhost:8080/api/health/hive

3. 查看接口文档：
   http://localhost:8080/doc.html

4. 测试数据分析接口：
   http://localhost:8080/api/analysis/overview

【核心API接口】
- GET  /api/analysis/overview           数据概览
- GET  /api/analysis/scenic/list        景区列表
- GET  /api/analysis/visitor-count      客流量统计
- GET  /api/analysis/review-stats       评价统计
- GET  /api/analysis/season-pattern     季节性分析
- GET  /api/analysis/scenic/ranking     景区排行榜

【常见问题】
Q1: Hive连接失败
A: 检查Hive服务是否启动，端口10000是否可访问

Q2: 查询数据为空
A: 确认Flask爬虫已成功爬取数据到HDFS的/tourism/raw/目录

Q3: 依赖下载慢
A: 配置Maven镜像，使用阿里云镜像
