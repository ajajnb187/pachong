# 福州旅游大数据分析系统 - 一键部署指南

## 📋 部署前提条件

### 必备软件
- ✅ **Docker Desktop** (Windows/Mac) 或 Docker Engine (Linux)
- ✅ **Docker Compose** (通常随Docker Desktop安装)
- ✅ **至少8GB可用内存**
- ✅ **至少20GB可用磁盘空间**

### 端口要求
确保以下端口未被占用：
- **9870** - Hadoop NameNode Web UI
- **9000** - HDFS
- **10000** - HiveServer2 JDBC
- **9083** - Hive Metastore Thrift
- **15432** - PostgreSQL (Hive Metastore)
- **6379** - Redis
- **23306** - MySQL (业务数据库)

## 🚀 一键部署步骤

### 第一步：确认Docker运行
```bash
# Windows PowerShell或CMD
docker --version
docker-compose --version

# 应该看到类似输出：
# Docker version 24.x.x
# Docker Compose version v2.x.x
```

### 第二步：进入项目docker目录
```bash
cd "d:\桌面\基于Hadoop和Hive的旅游景区数据分析与可视化系统的设计与实现以福州旅游为例\docker"
```

### 第三步：双击运行部署脚本
```
直接双击： deploy.bat
```

或者在命令行执行：
```bash
.\deploy.bat
```

### 第四步：等待部署完成
部署脚本会自动完成以下步骤：

1. **[1/6]** 停止并清理旧环境
2. **[2/6]** 拉取Docker镜像（首次运行需要下载，约5-10分钟）
3. **[3/6]** 启动基础服务（Hadoop, PostgreSQL, Redis, MySQL）
4. **[4/6]** 等待基础服务启动（60秒）
5. **[5/6]** 启动Hive服务（Metastore和HiveServer2）
6. **[6/6]** 等待Hive服务完全启动（120秒）
7. **[完成]** 初始化HDFS目录
8. **验证服务状态**
9. **测试Hive连接**

**预计总时间**：首次部署约15分钟，后续部署约5分钟

### 重启服务
```bash

docker-compose restart hive-server

# 重启所有服务
docker-compose restart
```

### 停止服务
```bash
# 停止所有服务（保留数据）
docker-compose stop

# 停止并删除容器（保留数据卷）
docker-compose down

# 停止并删除所有（包括数据）
docker-compose down -v
```

### 重新部署
```bash
# 完全清理后重新部署
docker-compose down -v
docker volume prune -f
.\deploy.bat
```

## 🔍 故障排查

### 问题1：容器启动失败
**现象**：`docker-compose ps` 显示某个容器状态为 `Exited` 或 `Restarting`

**解决**：
```bash
# 查看失败容器的日志
docker-compose logs [容器名]

# 常见原因：端口被占用
# 解决：关闭占用端口的程序，或修改docker-compose.yml中的端口映射
```

### 问题2：Hive连接失败
**现象**：`beeline` 连接超时或被拒绝

**解决**：
```bash
# 1. 检查hive-metastore是否正常
docker logs hive-metastore --tail 50

# 2. 检查hive-server是否正常
docker logs hive-server --tail 50

# 3. 如果metastore有schema错误，完全重新部署
docker-compose down -v
.\deploy.bat
```

### 问题3：HDFS权限错误
**现象**：无法上传文件到HDFS

**解决**：
```bash
# 修改HDFS权限
docker exec namenode hdfs dfs -chmod -R 777 /tourism
```

### 问题4：内存不足
**现象**：容器频繁重启，或Docker Desktop报内存不足

**解决**：
- 在Docker Desktop设置中增加内存限制（建议至少8GB）
- 关闭其他占用内存的应用

### 问题5：镜像拉取失败
**现象**：`docker-compose pull` 超时或失败

**解决**：
```bash
# 配置Docker镜像源（中国大陆用户）
# 在Docker Desktop设置 -> Docker Engine中添加：
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://registry.docker-cn.com"
  ]
}
```

数据上传后需要修复分区：
```bash
docker exec hive-server /opt/hive/bin/beeline -u jdbc:hive2://localhost:10000 -e "
USE tourism_db;
MSCK REPAIR TABLE scenic_spots;
MSCK REPAIR TABLE fuzhou_reviews;
"
```

```bash
docker exec hive-server /opt/hive/bin/beeline -u jdbc:hive2://localhost:10000 -e "
USE tourism_db;
SELECT COUNT(*) FROM scenic_spots;
SELECT COUNT(*) FROM fuzhou_reviews;
SELECT * FROM scenic_spots LIMIT 10;
"
```
