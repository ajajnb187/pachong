## 三、数据库表设计

### 3.1 MySQL表（业务数据）

```sql
-- 用户表
CREATE TABLE `user` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) UNIQUE NOT NULL COMMENT '用户名',
  `password` VARCHAR(255) NOT NULL COMMENT '密码',
  `nickname` VARCHAR(50) COMMENT '昵称',
  `email` VARCHAR(100) COMMENT '邮箱',
  `phone` VARCHAR(20) COMMENT '手机号',
  `avatar` VARCHAR(255) COMMENT '头像',
  `role` VARCHAR(20) DEFAULT 'user' COMMENT '角色',
  `status` TINYINT DEFAULT 1 COMMENT '状态:0禁用,1启用',
  `last_login_time` DATETIME COMMENT '最后登录时间',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted` TINYINT DEFAULT 0 COMMENT '删除标记:0未删除,1已删除',
  INDEX `idx_username` (`username`),
  INDEX `idx_role` (`role`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

-- 爬虫任务表（与Flask共用）
-- 已在tourism_db中创建
```

### 3.2 Hive表（分析数据）

```sql
-- 福州景区评论数据表（外部表）
CREATE EXTERNAL TABLE IF NOT EXISTS fuzhou_reviews (
    review_id STRING COMMENT '评论ID',
    spot_id STRING COMMENT '景区ID',
    spot_name STRING COMMENT '景区名称',
    visitor_name STRING COMMENT '游客昵称',
    rating DOUBLE COMMENT '评分',
    review_content STRING COMMENT '评论内容',
    review_images STRING COMMENT '评论图片',
    travel_date STRING COMMENT '旅游日期',
    review_date STRING COMMENT '评论日期',
    helpful_count INT COMMENT '点赞数',
    visitor_level STRING COMMENT '游客等级',
    visitor_location STRING COMMENT '游客地区',
    data_source STRING COMMENT '数据来源',
    crawl_time STRING COMMENT '爬取时间'
)
ROW FORMAT SERDE 'org.apache.hive.hcatalog.data.JsonSerDe'
STORED AS TEXTFILE
LOCATION '/tourism/raw/';

-- 日度统计表
CREATE TABLE IF NOT EXISTS dws_scenic_daily_stats (
    spot_id STRING COMMENT '景区ID',
    spot_name STRING COMMENT '景区名称',
    stat_date STRING COMMENT '统计日期',
    visitor_count INT COMMENT '游客数量',
    review_count INT COMMENT '评论数量',
    avg_rating DOUBLE COMMENT '平均评分',
    positive_rate DOUBLE COMMENT '好评率',
    dt STRING COMMENT '分区日期'
)
PARTITIONED BY (dt STRING)
STORED AS PARQUET;

-- 月度统计表
CREATE TABLE IF NOT EXISTS dws_scenic_monthly_stats (
    spot_id STRING COMMENT '景区ID',
    spot_name STRING COMMENT '景区名称',
    stat_month STRING COMMENT '统计月份',
    total_visitors INT COMMENT '总游客数',
    total_reviews INT COMMENT '总评论数',
    avg_rating DOUBLE COMMENT '平均评分',
    dt STRING COMMENT '分区日期'
)
PARTITIONED BY (dt STRING)
STORED AS PARQUET;

-- 景区排行榜表
CREATE TABLE IF NOT EXISTS ads_scenic_ranking (
    rank_no INT COMMENT '排名',
    spot_id STRING COMMENT '景区ID',
    spot_name STRING COMMENT '景区名称',
    metric_value BIGINT COMMENT '指标值',
    rank_type STRING COMMENT '排行类型',
    rank_period STRING COMMENT '统计周期',
    dt STRING COMMENT '分区日期'
)
PARTITIONED BY (dt STRING)
STORED AS PARQUET;
```

## 四、API接口清单

### 4.1 认证接口
- POST /api/auth/login - 用户登录
- POST /api/auth/register - 用户注册
- GET /api/auth/userinfo - 获取用户信息
- PUT /api/auth/update - 更新用户信息

### 4.2 景区接口
- GET /api/scenic/list - 景区列表
- GET /api/scenic/detail/{id} - 景区详情
- GET /api/scenic/ranking - 景区排行榜

### 4.3 分析接口
- GET /api/analysis/overview - 数据概览
- GET /api/analysis/visitor-count - 客流量统计
- GET /api/analysis/review-stats - 评价统计
- GET /api/analysis/season-pattern - 季节性分析
- GET /api/analysis/visitor-source - 客源地分布
- GET /api/analysis/holiday-impact - 节假日影响

### 4.4 爬虫管理接口
- GET /api/crawler/tasks - 爬虫任务列表
- GET /api/crawler/task/{id} - 任务详情
