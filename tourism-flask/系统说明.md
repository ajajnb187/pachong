# 福州旅游景区数据采集系统

## 系统概述

本系统为**管理员提供一键爬取福州所有景区评论数据的功能**，数据自动存储到Hadoop HDFS，供Hive分析使用。

---

## 核心功能

### ✅ 管理员一键数据采集

**功能**：一键爬取福州所有热门景区的用户评论数据

**数据来源**：携程旅行（移动端API）

**数据内容**：
- 景区信息（ID、名称）
- 用户评论（评分、内容）
- 时间信息（旅游日期、评论日期）
- 用户信息（昵称、等级、地区）

**数据特点**：
- 真实用户评论（非模拟数据）
- 历史季节性数据（近10年）
- 覆盖四季（春夏秋冬）
- 支持趋势分析

---

## 快速使用

### 1. 启动服务
```bash
start.bat
```

### 2. 调用管理员API
```bash
curl -X POST http://localhost:5000/api/admin/crawl/fuzhou \
  -H "Content-Type: application/json" \
  -d '{"target_count": 500}'
```

**参数说明**：
- `target_count`: 目标数据量（默认500条）

### 3. 查看结果

数据自动保存到：`data/raw/日期/ctrip_fuzhou_任务ID_时间.jsonl`

示例：`data/raw/20251211/ctrip_fuzhou_20_021823.jsonl`

## 数据格式

### JSONL格式（适合Hive）

每行一条JSON记录：
```json
{"review_id":"uuid","spot_id":"64505","spot_name":"三坊七巷","visitor_name":"张三","rating":5.0,"review_content":"很不错","review_images":"[]","travel_date":"2024-10-12","review_date":"2024-10-12","helpful_count":0,"visitor_level":"","visitor_location":"","data_source":"ctrip","crawl_time":"2025-12-11 02:00:00"}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| review_id | STRING | 评论唯一ID |
| spot_id | STRING | 景区ID |
| spot_name | STRING | 景区名称 |
| visitor_name | STRING | 游客昵称 |
| rating | DOUBLE | 评分(1-5) |
| review_content | STRING | 评论内容 |
| review_images | STRING | 评论图片JSON |
| travel_date | STRING | 旅游日期 |
| review_date | STRING | 评论日期 |
| helpful_count | INT | 点赞数 |
| visitor_level | STRING | 游客等级 |
| visitor_location | STRING | 游客地区 |
| data_source | STRING | 数据来源 |
| crawl_time | STRING | 爬取时间 |

## Hive建表

```sql
CREATE EXTERNAL TABLE fuzhou_reviews (
    review_id STRING,
    spot_id STRING,
    spot_name STRING,
    visitor_name STRING,
    rating DOUBLE,
    review_content STRING,
    review_images STRING,
    travel_date STRING,
    review_date STRING,
    helpful_count INT,
    visitor_level STRING,
    visitor_location STRING,
    data_source STRING,
    crawl_time STRING
)
ROW FORMAT SERDE 'org.apache.hive.hcatalog.data.JsonSerDe'
STORED AS TEXTFILE
LOCATION '/tourism/data/raw/';
```

## 分析示例

### 景区热度排行
```sql
SELECT spot_name, COUNT(*) as review_count
FROM fuzhou_reviews
GROUP BY spot_name
ORDER BY review_count DESC;
```

### 季节性分析
```sql
SELECT 
    MONTH(travel_date) as month,
    COUNT(*) as count,
    AVG(rating) as avg_rating
FROM fuzhou_reviews
GROUP BY MONTH(travel_date)
ORDER BY month;
```
