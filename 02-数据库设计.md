# 福州旅游景区数据分析与可视化系统 - 数据库设计

## 一、数据库架构

### 1.1 数据库分层

本系统采用**混合存储架构**：

```
┌────────────────────────────────────────────────────┐
│              MySQL (关系型数据库)                    │
│  • 用户账号信息                                     │
│  • 系统配置信息                                     │
│  • 爬取任务记录                                     │
│  • 数据源配置                                       │
└────────────────────────────────────────────────────┘
                         ↕
┌────────────────────────────────────────────────────┐
│            Hadoop HDFS (分布式文件系统)             │
│  • 原始爬取数据（JSON/CSV格式）                     │
│  • 清洗后的结构化数据                               │
│  • 历史数据归档                                     │
└────────────────────────────────────────────────────┘
                         ↕
┌────────────────────────────────────────────────────┐
│              Hive (数据仓库)                        │
│  • 景区基本信息表                                   │
│  • 游客评价数据表                                   │
│  • 游客行为数据表                                   │
│  • 统计分析结果表                                   │
└────────────────────────────────────────────────────┘
```

## 二、MySQL数据库设计

### 2.1 用户管理表

#### 2.1.1 sys_user (用户表)

| 字段名 | 类型 | 长度 | 主键 | 非空 | 默认值 | 说明 |
|--------|------|------|------|------|--------|------|
| id | BIGINT | - | √ | √ | 自增 | 用户ID |
| username | VARCHAR | 50 | - | √ | - | 用户名（登录账号） |
| password | VARCHAR | 100 | - | √ | - | 密码（加密存储） |
| nickname | VARCHAR | 50 | - | - | - | 昵称 |
| email | VARCHAR | 100 | - | - | - | 邮箱 |
| phone | VARCHAR | 20 | - | - | - | 手机号 |
| avatar | VARCHAR | 200 | - | - | - | 头像URL |
| role | VARCHAR | 20 | - | √ | 'admin' | 角色（admin-管理员） |
| status | TINYINT | - | - | √ | 1 | 状态（0-禁用，1-启用） |
| create_time | DATETIME | - | - | √ | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | - | - | √ | CURRENT_TIMESTAMP | 更新时间 |
| last_login_time | DATETIME | - | - | - | - | 最后登录时间 |

```sql
CREATE TABLE `sys_user` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) NOT NULL COMMENT '用户名',
  `password` VARCHAR(100) NOT NULL COMMENT '密码',
  `nickname` VARCHAR(50) DEFAULT NULL COMMENT '昵称',
  `email` VARCHAR(100) DEFAULT NULL COMMENT '邮箱',
  `phone` VARCHAR(20) DEFAULT NULL COMMENT '手机号',
  `avatar` VARCHAR(200) DEFAULT NULL COMMENT '头像',
  `role` VARCHAR(20) NOT NULL DEFAULT 'admin' COMMENT '角色',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态 0-禁用 1-启用',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `last_login_time` DATETIME DEFAULT NULL COMMENT '最后登录时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 2.2 数据采集管理表

| 字段名 | 类型 | 长度 | 主键 | 非空 | 默认值 | 说明 |
|--------|------|------|------|------|--------|------|
| id | BIGINT | - | √ | √ | 自增 | 任务ID |

| scenic_spot_name | VARCHAR | 100 | - | √ | - | 景区名称 |

| actual_count | INT | - | - | √ | 0 | 实际爬取数量 |
| status | VARCHAR | 20 | - | √ | 'pending' | 状态（pending-等待，running-运行中，success-成功，failed-失败） |
| progress | INT | - | - | √ | 0 | 进度（0-100） |
| start_time | DATETIME | - | - | - | - | 开始时间 |
| end_time | DATETIME | - | - | - | - | 结束时间 |
| error_msg | TEXT | - | - | - | - | 错误信息 |
| hdfs_path | VARCHAR | 500 | - | - | - | HDFS存储路径 |
| create_by | BIGINT | - | - | √ | - | 创建人ID |
| create_time | DATETIME | - | - | √ | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | - | - | √ | CURRENT_TIMESTAMP | 更新时间 |

```sql
CREATE TABLE `crawler_task` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '任务ID',
  `task_name` VARCHAR(100) NOT NULL COMMENT '任务名称',
  `scenic_spot_name` VARCHAR(100) NOT NULL COMMENT '景区名称',
  `data_source` VARCHAR(50) NOT NULL COMMENT '数据来源',
  `target_count` INT NOT NULL DEFAULT 100 COMMENT '目标爬取数量',
  `actual_count` INT NOT NULL DEFAULT 0 COMMENT '实际爬取数量',
  `status` VARCHAR(20) NOT NULL DEFAULT 'pending' COMMENT '任务状态',
  `progress` INT NOT NULL DEFAULT 0 COMMENT '进度',
  `start_time` DATETIME DEFAULT NULL COMMENT '开始时间',
  `end_time` DATETIME DEFAULT NULL COMMENT '结束时间',
  `error_msg` TEXT DEFAULT NULL COMMENT '错误信息',
  `hdfs_path` VARCHAR(500) DEFAULT NULL COMMENT 'HDFS存储路径',
  `create_by` BIGINT NOT NULL COMMENT '创建人',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_status` (`status`),
  KEY `idx_scenic_spot` (`scenic_spot_name`),
  KEY `idx_create_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='爬取任务表';
```

## 三、Hive数据仓库设计

### 3.1 数据分层设计

```
ODS层（原始数据层）
    ↓
DWD层（明细数据层）
    ↓
DWS层（汇总数据层）
    ↓
ADS层（应用数据层）
```

### 3.2 ODS层（原始数据层）

#### 3.2.1 ods_scenic_spot_info (景区基本信息表)

```sql
CREATE EXTERNAL TABLE IF NOT EXISTS ods_scenic_spot_info (
    spot_id STRING COMMENT '景区ID',
    spot_name STRING COMMENT '景区名称',
    spot_type STRING COMMENT '景区类型',
    location STRING COMMENT '所在位置',
    address STRING COMMENT '详细地址',
    longitude DOUBLE COMMENT '经度',
    latitude DOUBLE COMMENT '纬度',
    open_time STRING COMMENT '开放时间',
    ticket_price DECIMAL(10,2) COMMENT '门票价格',
    description STRING COMMENT '景区描述',
    images STRING COMMENT '图片列表（JSON数组）',
    contact_phone STRING COMMENT '联系电话',
    official_website STRING COMMENT '官方网站',
    rating DOUBLE COMMENT '综合评分',
    data_source STRING COMMENT '数据来源',
    crawl_time STRING COMMENT '爬取时间'
)
COMMENT '景区基本信息表'
PARTITIONED BY (dt STRING COMMENT '日期分区 yyyyMMdd')
```

## 五、数据字典

### 5.1 景区类型枚举
- `NATURAL`：自然风光
- `HISTORICAL`：历史文化
- `THEME_PARK`：主题公园
- `SCENIC_AREA`：风景名胜区
- `CULTURAL`：文化景点

### 5.2 游客等级枚举
- `BRONZE`：青铜会员
- `SILVER`：白银会员
- `GOLD`：黄金会员
- `PLATINUM`：铂金会员
- `DIAMOND`：钻石会员

### 5.3 季节枚举
- `SPRING`：春季（3-5月）
- `SUMMER`：夏季（6-8月）
- `AUTUMN`：秋季（9-11月）
- `WINTER`：冬季（12-2月）
