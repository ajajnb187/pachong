# 福州旅游景区数据分析系统 - 论文需求功能清单

## 📋 根据论文明确需求实现

### 论文核心需求（第4.1节）

> **数据需求分析**：  
> 1. **游客数量数据** - 了解各个景区的客流量情况，以及不同季节和节假日的客流变化趋势  
> 2. **景区评价数据** - 评估景区的服务质量和吸引力  
> 3. **季节性数据** - 分析不同季节对景区游客数量和评价的影响

### 论文数据分析内容（第7.1节）

> **数据分析阶段**：  
> 1. **游客行为分析**：游客流量的时间分布、停留时间、游览路径、消费行为  
> 2. **景区运营状况**：设施利用率、投诉率、收入构成  
> 3. **旅游市场动态**：旅游淡旺季分布、客源地分布、游客年龄性别结构

#### POST /api/auth/login
**功能**：管理员登录（论文第5节）

    "password": "123456"

## 🚀 技术实现

### 核心技术栈
- **Spring Boot 2.7.18** - Web框架
- **Hive JDBC 3.1.2** - 大数据查询⭐
- **SaToken 1.37.0** - 权限认证
- **MyBatis Plus 3.5.3** - MySQL操作
- **Redis** - Token存储

### Hive查询实现
所有数据分析功能都通过Hive JDBC直接查询HDFS中Flask爬取的福州景区数据：

```java
@Autowired
@Qualifier("hiveJdbcTemplate")
private JdbcTemplate hiveJdbcTemplate;

// 示例：查询客流量
String sql = "SELECT travel_date, COUNT(*) as visitor_count " +
             "FROM fuzhou_reviews " +
             "WHERE spot_id = ? AND travel_date >= ? AND travel_date <= ? " +
             "GROUP BY travel_date ORDER BY travel_date";

List<Map<String, Object>> result = hiveJdbcTemplate.query(sql, params);
```

## 📌 使用说明

### 1. 启动应用
```bash
mvn spring-boot:run
```

### 2. 访问接口文档
```
http://localhost:8080/doc.html
```

### 3. 测试核心功能
```bash
# 1. 登录获取token
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'

# 2. 查询客流量（游客数量数据）
curl "http://localhost:8080/api/analysis/visitor-count?spotId=64505&startDate=2024-01-01&endDate=2024-12-31" \
  -H "satoken: your-token"

curl "http://localhost:8080/api/analysis/season-pattern?spotId=64505&year=2024" \
  -H "satoken: your-token"

# 4. 查询评价统计
curl "http://localhost:8080/api/analysis/review-stats?spotId=64505" \
  -H "satoken: your-token"
```
