# 快速启动指南

## 1. 启动服务

### 方式一：使用启动脚本（推荐）
```bash
start.bat
```

### 方式二：手动启动
```bash
# 终端1：启动Flask服务
.venv\Scripts\python.exe app.py

# 终端2：启动Celery Worker
.venv\Scripts\celery.exe -A celery_worker.celery_app worker --loglevel=info -P solo
```

## 2. 一键爬取福州所有景区数据

### 使用curl命令
```bash
curl -X POST http://localhost:5000/api/admin/crawl/fuzhou \
  -H "Content-Type: application/json" \
  -d "{\"target_count\": 500}"
```

### 使用Python脚本
```python
import requests

response = requests.post(
    'http://localhost:5000/api/admin/crawl/fuzhou',
    json={'target_count': 500}
)

print(response.json())
```

## 3. 查看任务状态

假设返回的任务ID是20：
```bash
curl http://localhost:5000/api/crawler/status/20
```

## 4. 查看爬取的数据

数据存储在：`data/raw/YYYYMMDD/ctrip_fuzhou_任务ID_时间.jsonl`

示例：
```bash
cat data/raw/20251211/ctrip_fuzhou_20_020000.jsonl
```
